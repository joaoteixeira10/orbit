# Holiday Themes — Spec

Exact values live in `holiday-themes.ts`, and keyframes live in `holiday-themes.css`. This document explains what each value does and how the pieces fit together.

## 1. Goal

For a few weeks around a holiday, Orbit's Today screen takes on a festive skin. The layout and content stay the same. Only these change:

- **Colours:** the full surface and accent palette, for both light and dark mode.
- **Decorations:** hanging decor along the top of the main column, plus an optional particle overlay (snow, bats, confetti, petals).
- **Small brand moments:** the logo, the Today tile, a countdown chip by the greeting, art in the card corners, and the completed-task check.

The theme must never get in the way of the user. Decorations are non-interactive, sit outside the text, can be turned off, and respect reduced motion.

## 2. Architecture

```
mode (light | dark)  ──┐
                       ├─► resolveTheme() ─► CSS variables on the app root
holiday (auto/off/id) ─┘                    + <HolidayDecor/> overlay layer
```

- `holiday-themes.ts` exports `HOLIDAYS: Holiday[]`. Each entry has `tokens.light`, `tokens.dark`, `art`, `decor`, `particles`, `copy` and `window`.
- **Resolution:**
  1. A user override wins.
  2. If the setting is `auto`, use the first holiday whose `window` contains today (local time).
  3. Otherwise, use the normal theme.
- **Application:** write each token as a CSS custom property on the root container, e.g. `--h-bg`. In normal mode the holiday variables are unset and the components fall back to the existing theme variables, e.g. `var(--h-bg, var(--bg))`. If the app uses a JS theme object instead, merge the tokens into it. Follow whatever pattern the codebase already uses.
- **Decorations:** render them in one absolutely positioned layer per region:
  - the hanging layer at the top of the main column, z-index above the content background but below popovers;
  - the particle layer over the whole window.

  Both layers use `pointer-events: none` and `aria-hidden="true"`.

## 3. Token roles

Every holiday defines the same keys for both light and dark mode:

| Token | Drives |
|---|---|
| `bg` | Main column background |
| `side` | Sidebar background |
| `card` | Cards (Today, Up Next), quick-capture input, quick tiles |
| `cardLine` | 1px card borders and dividers |
| `rowLine` | Divider between task rows |
| `hover` | Row and nav hover fill |
| `field` | Search field, sidebar effects-toggle row |
| `text` | Primary text |
| `muted` | Secondary text: meta, section labels, placeholders, icons |
| `faint` | Completed task title, disabled |
| `primary` | "Today" card heading, notification badge |
| `secondary` | "Up Next" card heading |
| `icon` | Sidebar nav icons, date eyebrow ("WEDNESDAY 4 NOVEMBER"), flag, due-today dates |
| `tag` | `#tags` and issue links |
| `late` | Overdue dates, `!!!` |
| `prio1`, `prio2`, `prio3` | Priority marks `!`, `!!`, `!!!` |
| `check` | Empty checkbox ring |
| `switchOff` | Off-state track of the effects toggle |
| `glow` | Soft radial glow at the top of the main column: `radial-gradient(ellipse 70% 40% at 45% -8%, glow, transparent 70%)` |
| `chipBg`, `chipText`, `chipLine` | Countdown chip (inset 1px ring in `chipLine`) |
| `thread`, `wire` | Strings that decorations hang from |
| `flake` | Particle tint, where a holiday tints its particles by mode |
| `cap`, `capLine` | Christmas snow-cap fill and stroke |

Light-mode accents are deliberately darker than dark-mode ones, so they keep at least 4.5:1 contrast for text on `card`/`bg`. Use the values as given.

## 4. Static styling per holiday

All of these come from `art` in the config:

- **Logo** (`art.logo`): a 28×28 SVG that replaces the Orbit planet mark in the sidebar header.
- **Today tile** (`art.tile`):
  - `background` is a gradient on the selected "Today" quick tile.
  - `overlay` is an absolutely positioned pattern layer (candy stripes, pumpkin ribs, azulejo grid, polka dots).
  - The icon box stays white with its icon stroke set to `art.tileIcon`.
  - Label text is white.
- **Icon boxes** (`art.iconBoxes`): solid fills for the Calendar tile, Quick Notes, Quick Draw, My files, the workspace badge and the avatar.
- **Countdown chip** (`copy.chip(daysLeft)` + `art.chipIcon`): a pill after the greeting. It shows the number of days until `window.peak`. On the peak day, show `copy.chipToday`. NYE switches to hours on Dec 31.
- **Card corner art** (`art.cardCorner`), on the Today card, plus Up Next where noted:
  - `snowcap`: a white wavy SVG sitting on the top edge (top −7px, inset 16px left and right, height 14px, drop shadow `0 1px 1px rgba(0,0,0,.3)`). Use a different path for each card.
  - `cobweb`: a 76×76 SVG generated by `cobwebPath()`, anchored to the top-right corner, stroke `thread`-ish, 0.8px.
  - `svg`: 40×40 art at top 12px, right 14px.
- **Completed check:** a 22px circle filled with `radial-gradient(circle at 35% 30%, done[0], done[1] 70%)`, glow `0 0 10px done[2]`, and a white check.
- **Event bars:** the 4px left bar on Up Next events.
  - Map the app's calendar colour slots to `art.bars` in order.
  - Festive events (from the holiday's own calendar, or matched by a keyword the user tags) get `art.festiveBar`, a striped gradient.
- **Quick-capture placeholder:** `copy.placeholder`.
- **Extras:** Halloween adds a moon in the top-right of the main column (`art.moon`).

## 5. Hanging decorations (`decor`)

These are rendered in an absolutely positioned layer at the top of the main column. The header starts 58px down to leave room for them.

| kind | Used by | Build |
|---|---|---|
| `lights` | Christmas | `lightsLayout(N=24)`. A scalloped wire SVG (`preserveAspectRatio="none"`, `vector-effect: non-scaling-stroke`, stroke `wire`) with a bulb at the bottom of each scallop. A bulb is an 8×12 rounded shape plus a 5×4 cap. Colours cycle `#ff4d5e #ffc94a #4fd18b #fff3d6`. Each bulb has glow `0 0 10px 2px <color>88`, alternates ±9° rotation and plays `twinkle` with a random duration of 1.8–3.4s and a negative delay. |
| `drop` | Halloween (spiders), NYE (stars), Easter (eggs), Lunar NY (lanterns) | Each item is `[x%, threadLength, scale]`. The wrapper sits at top −12px and is centred on x. It holds a 1px thread of `threadLength + 12`px in `thread`, then the item SVG at `scale * 1.2`. It plays `bob` (2.4–4s alternate). Keep items in the right ~40% of the column so they never cover the greeting or quick-capture text. |
| `bunting` | Santos Populares | `buntingLayout(N=6 scallops, Q=40 depth, k=7 flags/scallop)`. Flags are 14×18 triangles placed along each quadratic curve. Colours cycle red, yellow, green, blue, pink, orange. Each flag plays `sway` (±6°, top-centre origin). |

## 6. Particles (`particles`)

Particles render in a full-window overlay with `overflow: hidden`, `pointer-events: none` and z-index above the content.

- **`fall`:** starts at top −20px at a random x%. Animated with `fallL`/`fallR` (moves 930px down and ±50px sideways). Duration comes from `dur` and the delay is negative, so the screen starts already populated.
- **`rise`:** starts at top 0 with `rise` (from 940px down to −60px).
- **`fly`** (Halloween bats): the wrapper plays `flyA`/`flyB` across the full window width, and the inner SVG plays `flap` (scaleY 1 → 0.35, 0.14–0.24s alternate).
- **Spin:** a `spin` value of `fast` (1.2–3.2s) or `slow` (4–8s) on the inner element via `spin3d`. Without spin, particles sway.
- **Randomness:** use the seeded `rnd(i, k)` in the config so layouts are stable between renders.
- **Counts** are tuned for a 1440×900 window. Scale them by the viewport area: `count * (w*h)/(1440*900)`, capped at the configured count.
- **Performance:**
  - Animate only `transform` and `opacity`.
  - Pause all animation when the window is hidden (`document.visibilityState`).
  - Unmount the particle layer when effects are off.

## 7. Motion and accessibility

- With `prefers-reduced-motion: reduce`, keep the static art (colours, logo, tile, corner art, hanging decor in a still pose) and do not mount particles or any infinite animation.
- All decoration nodes are `aria-hidden`. Text contrast is unchanged in meaning: muted stays muted and late stays red-ish.
- Decorations must never overlap interactive controls. If the main column is narrower than 900px, hide the `drop` items and the moon, and keep the lights or bunting.

## 8. Behaviour and settings

- **Settings → Appearance:**
  - **Holiday themes:** `Auto` (default) · `Off` · one entry per holiday (preview or force it).
  - **Effects:** on (default) or off. This controls particles only.
- **Sidebar toggle:** the bottom of the sidebar shows a compact row with the holiday's `art.toggleIcon`, `copy.effectsLabel` ("Let it snow", "Spooky effects", "Confetti", …) and a switch. It mirrors the Effects setting, and the switch's on colour is `art.iconBoxes.calendar`. Show the row only while a holiday theme is active.
- **Windows** (`window` in the config, local dates):

| Holiday | Window | Peak (countdown target) |
|---|---|---|
| Halloween | Oct 15 – Nov 1 | Oct 31 |
| Christmas | Dec 1 – Dec 26 | Dec 25 |
| New Year's Eve | Dec 27 – Jan 1 | Jan 1 00:00 (hours on Dec 31) |
| Easter | Palm Sunday – Easter Monday (computed with `easterSunday(year)`) | Easter Sunday |
| Santos Populares | Jun 1 – Jun 30 | Jun 13 (Santo António) |
| Lunar New Year | 7 days before – 15 days after the date in `LUNAR_NEW_YEAR` | that date |

  The windows don't overlap. If they ever do, the first match in array order wins.
- **Persistence:** store the override and the effects flag in the app's existing preferences store.

## 9. Copy

These strings come from each holiday's `copy` and should go through i18n.

| Holiday | Chip | Effects label | Placeholder |
|---|---|---|---|
| Christmas | "{n} days to Christmas" | Let it snow | Jot something down… making a list, checking it twice |
| Halloween | "{n} days to Halloween" | Spooky effects | Jot something down… before it vanishes |
| New Year's Eve | "{n} hours to {year}" / "{n} days to {year}" | Confetti | Jot something down… resolutions welcome |
| Easter | "{n} days to Easter" | Spring petals | Jot something down… before the egg hunt |
| Santos Populares | "{n} days to Santo António" | Arraial confetti | Jot something down… a quadra for the manjerico? |
| Lunar New Year | "{n} days to Lunar New Year" | Blossoms | Jot something down… wishes for the new year |

Use "1 day" for singular and `chipToday` on the peak day ("Merry Christmas", "Happy Halloween", …).

## 10. Acceptance checklist

- [ ] With the theme off, the app looks exactly as it does today, in both light and dark.
- [ ] Each of the 6 holidays × 2 modes matches its reference: background, sidebar, cards, headings, nav icons, tile, logo, chip and corner art.
- [ ] Auto mode picks the correct holiday for a date inside each window and none outside. Test with a mocked clock, including Easter in 2027 (Mar 28) and 2028 (Apr 16), and Lunar New Year 2027 (Feb 6).
- [ ] The countdown handles plurals and the peak day, and NYE switches to hours on Dec 31.
- [ ] Decorations never intercept clicks. Hovering and clicking tasks, the input and the nav all work under the layers.
- [ ] Hanging decor never overlaps the greeting or quick-capture text at the minimum window width.
- [ ] Reduced motion: no particles and no infinite animations.
- [ ] The Effects toggle (in Settings and in the sidebar) shows and hides particles instantly and persists across restarts.
- [ ] No frame drops while scrolling the Today list with effects on (check the profiler), and animations pause when the window is hidden.
- [ ] Text contrast is ≥ 4.5:1 for body text and ≥ 3:1 for headings and icons in every theme × mode.
